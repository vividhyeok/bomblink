# Bomb Link Reconstruction

2000년대 삼성 애니콜/DoCoMo 계열 피처폰에서 즐길 수 있었던 **Bomb Link**의 플레이 규칙을 공개 자료를 바탕으로 재구성하는 비공식 웹 프로젝트입니다.

원본 ROM, 그래픽, 사운드 리소스는 포함하지 않습니다. 목표는 원작 자산 복제가 아니라 **규칙과 플레이 감각의 재현**입니다.

## 현재 복원된 핵심 규칙

- 보드: 5열 × 8 logical rows
- 실제 조작 영역: 상단 7행
- 최하단 1행: 다음에 올라올 폭탄을 보여주는 preview row
- 일반 폭탄은 **심지 방향을 하나만** 가집니다.
- 폭탄 A가 터질 때 옆 폭탄 B의 심지가 **A를 향하고 있어야** B로 불이 전달됩니다.
- 좌우 가장자리의 불꽃에 바깥쪽 심지를 연결하면 최초 폭발이 시작됩니다.
- 폭발 중에는 해당 불꽃이 멈추고 다른 폭탄을 계속 조작할 수 있습니다.
- 폭발/중력이 끝나면 같은 불꽃이 다시 내려가므로, 한 번의 불꽃으로 여러 chain을 만들 수 있습니다.
- X / Shift 또는 화면의 `RAISE` 버튼으로 폭탄을 직접 한 줄 끌어 올릴 수 있습니다.
- bonus / obstruction 특수 폭탄을 일부 재구성했습니다.

## 심지 표시 읽는 법

PC 화면에서 방향을 즉시 읽을 수 있도록 원작보다 연결 상태를 명확하게 보여줍니다.

- **밝은 아이보리 실선**: 다른 폭탄을 실제로 향하는 심지
- **금색 실선**: 좌/우 불꽃 rail을 향하는 심지
- **어두운 짧은 점선**: 빈 공간을 향하는 심지
- **삼각형 끝**: 해당 폭탄의 심지가 향하는 방향
- 선택 커서: green = bomb 연결 / gold = flame 연결 / red = 빈 공간

이 색상은 원작 픽셀 아트를 그대로 복사한 것이 아니라 PC에서 Bomb Link의 방향성 규칙을 읽기 쉽게 만든 reconstruction UI입니다.

## 특수 폭탄

- `B2 / B3 / B4`: 큰 chain에서 생성되는 bonus bomb의 현재 복원 표현. 회전할 수 없고 점수 계산에서 2/3/4 폭발 단위로 취급합니다.
- 사각형 탱크형: obstruction/square bomb. 회전할 수 없으며 difficulty가 높을수록 더 자주 등장하도록 구성되어 있습니다.

피처폰 보존 자료에 따라 9/18/27개 이상이 한 연속 chain으로 터질 때 B2/B3/B4를 예약합니다. 실제 원작의 2/3/4칸짜리 geometry는 아직 근거가 충분하지 않아 한 칸짜리 proxy로 구현되어 있습니다.

## 실행

```bash
npm install
npm run dev
```

## 조작

| 입력 | 동작 |
| --- | --- |
| 방향키 / WASD | 커서 이동 |
| Space / Enter | 심지 시계 방향 회전 |
| Z / Backspace | 심지 반시계 방향 회전 |
| X / Shift | 한 줄 끌어 올리기 |
| M | 음소거 |
| R | 재시작 |
| Esc | 일시정지 |

모바일에서는 조이스틱, `ROTATE`, `RAISE` 버튼을 사용할 수 있습니다.

## 모드 / 난이도

원작 메뉴 UI 자체는 아직 재구성 중이며 현재는 URL 파라미터로 테스트할 수 있습니다.

```text
?mode=flames100&difficulty=normal
?mode=endless&difficulty=hard
```

- `mode=flames100`: 100 ATTACK. **불꽃 낙하 100회**를 기준으로 종료합니다.
- `mode=endless`: 게임 오버까지 계속 진행합니다.
- `difficulty=easy|normal|hard`

## 정확도 원칙

이 프로젝트에서는 확인된 규칙과 추정값을 분리합니다.

- `ORIGINAL_SPEC.md`: 원작 자료를 기준으로 한 복원 명세와 확신도/출처
- `RULE.MD`: 현재 코드가 실제로 구현하는 동작

추가 조사로 level-up 시 점수 bonus가 존재한다는 사실과 그 전략적 중요성까지는 확인됐지만, **정확한 level-up threshold와 bonus 점수 숫자**는 아직 찾지 못했습니다. 불꽃/자동 상승의 정확한 초 단위 표와 피처폰판 obstruction 등장 확률도 마찬가지입니다. 이런 숫자는 그럴듯한 값으로 위장하지 않고 교체 가능한 reconstruction tuning으로 남깁니다.
